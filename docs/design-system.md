# نظام تصميم تطبيق قمر الزمان — المرجع

> هوية فيروزية تحريرية مستمدة من شعار الخط العربي والزخرفة الورقية.

## الهوية اللونية — مصدر واحد

`lib/core/theme/app_colors.dart` هو **المصدر الوحيد**.

| الدور | الثابت | القيمة |
|---|---|---|
| فيروزي الشعار | `primary` | `#088898` |
| الغامق | `primaryDark` | `#0C7475` |
| الفاتح / الضباب | `primaryLight` / `primarySoft` / `mist` | `#E6F7F9` / `#F2FBFC` / `#E4F3F5` |
| لمسة فاتحة | `accent` | `#48C0D0` |
| خلفية الصفحة | `scaffold` | `#EEF8F9` |
| تباين العروض | `rose` | `#066A78` |

## الشكل

- زوايا عضوية: `AppRadius` من 12 إلى 36 (pill للتنقل والبحث)
- ظلال فيروزية ناعمة: `AppColors.cardShadow` / `floatShadow`
- عناوين الأقسام بخط ElMessiri + شريط متدرج رفيع
- شريط تنقل: كبسولة متدرجة حول الأيقونة النشطة
- بطاقات المنتجات: ظل خفيف + خلفية صورة ضبابية فيروزية

## الحركة

كما في `app_motion.dart` — مع `LeafArt` و`SuccessBurst` بأوراق زخرفية.
